🎀 Deadline Buddy

Your Cute & Smart Academic Planner

Deadline Buddy is an Android application designed to help university students organize assignments, manage deadlines, and track their daily activities.

✨ Implemented Features

- 👤 User Profile Management
- 📝 Assignment Management (Up to 10 Assignments)
- 📸 Assignment Image Attachment
- 🤖 Automatic Assignment Task Breakdown
- ✅ Daily To-Do List
- ☑️ Mark Tasks as Completed
- 📅 Calendar for Managing Deadlines
- 🔔 Deadline Reminders & Notifications
- 📊 Task Progress Tracking
- 🎀 Cute Hello Kitty Inspired Pink & White UI

🛠️ Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
